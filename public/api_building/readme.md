## BCC API

### Setup
- **Create an .env file by copying from included ".env.example"**
- **Run the command composer install**
- **Make sure the directory named "/public/resurces/cache" exists. Create one if needed**


## Accessing API and Parameters

Use the following slug to access the API
http://bcc_api.test/building/LMS4555
- **/building/ is the keyword**
- **/LMS4555 - Strata No. for the building**
